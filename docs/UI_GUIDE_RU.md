# Как пользоваться Sequencing Experiment Design Advisor

Интерфейс и расчёты работают локально. Для самого советника нужны Python 3.11 или новее и стандартная библиотека; отдельные зависимости научного анализа описаны в основном README.

## Запуск

1. Откройте терминал в папке проекта `sequencing-advisor`.
2. Выполните `python app.py`.
3. Откройте в браузере `http://127.0.0.1:8000`.
4. Чтобы остановить приложение, нажмите `Ctrl+C` в терминале.

Если порт занят, выполните `python app.py --port 8765` и откройте `http://127.0.0.1:8765`. Сам файл `web/index.html` без сервера не запускает модель.

## Демонстрация на защите

Начните с примера **Bacterial isolate · SNVs**. Это клональный гаплоидный изолят: частота аллеля 100% — исходная гипотеза для его SNV. Частота 50% означает смесь популяций, а не бактериальную диплоидную гетерозиготу.

Покажите три величины: эффективную глубину, полную оценку затрат и теоретическую границу поддержки аллеля. Измените частоту аллеля, бюджет и число образцов; объясните, почему советник сообщает о недостаточном бюджете вместо снижения требуемой глубины.

Переключитесь на **Human · 5% allele**. При требовании трёх альтернативных наблюдений с вероятностью 95% нужно приблизительно 126× эффективной глубины. Это математическая вероятность набрать наблюдения, а не измеренная чувствительность variant caller. Систематические ошибки, контаминация и ложноположительные вызовы в формулу не входят.

В **Bacterial · repeat assembly** сравните длину молекулы с повтором и двумя уникальными флангами. При выбранном полном разрешении повтора короткие чтения могут быть несовместимы с задачей даже при высоком покрытии. Достаточная длина — необходимый плановый фильтр, но не доказательство полной сборки.

В **RNA · two conditions** объясните, почему советник считает фрагменты и биологические реплики, а не глубину относительно генома. Увеличение числа чтений не заменяет независимые образцы. Порог в ppm — доля назначенных фрагментов для набора минимального числа наблюдений; это не TPM и не мощность дифференциальной экспрессии.

## Что означает блок Evidence

После анализа программа читает `results/saturation.json` и `results/summary.json`. При отсутствии результатов она прямо сообщает, что эмпирические кривые ещё не доступны. Результаты не генерируются из правил глубины.

Основной пилот измеряет ширину покрытия выбранного бактериального референса и долю выровненных чтений. При стандартном пути используются первичные выравнивания minimap2 и фильтр MAPQ ≥20 для ширины покрытия. Если доступен только учебный anchor mapper, интерфейс подписывает результат как алгоритмический proxy. Значение MAPQ — оценка aligner, а не измеренная точность.

Точки показывают средние по нескольким seeds, полоса — минимум и максимум. Это изменчивость технической выборки одного пула, а не доверительный интервал по независимым биологическим образцам. Если заданный критерий насыщения не выполнен, приложение не объявляет последнюю точку плато. Ширина покрытия не доказывает SNV recall, качество сборки или мощность RNA-seq.

## Стоимость и источники

Раздел **Count the whole experiment** раздельно показывает подготовку библиотек, QC, секвенирование, время прибора, вычисления, хранение и резерв. Shared run распределяет затраты по доле общего запуска; Dedicated оплачивает целые flow cells, включая неиспользованный выход.

Настройки находятся в `config/costs.json`. Для реального заказа замените подготовку, тарифы, выход и минимальный заказ подтверждённым предложением вашей лаборатории. Стандартная полоса ±30% — анализ сценария, а не статистически измеренная ошибка; сервисный заказ может стоить существенно дороже.

Проверка против цены реагентов производителя — арифметическая проверка исходного параметра. Независимые FY26 цены Northwestern NUSeq сравниваются с совпадающим объёмом затрат: опубликованный сервис секвенирования уже включает работу прибора. В интерфейсе показаны отклонения модели и различия конфигураций. Низкая стоимость подготовки в модели по сравнению с внешним сервисом не скрывается и ограничивает вывод о полной стоимости.

## Экспорт и воспроизводимость

- **Export design JSON** сохраняет вход, рекомендацию, альтернативы, формулы, источники, эмпирический контекст и SHA-256 конфигурации.
- **Save input** сохраняет только сценарий для повторного запуска.
- **Download current cost assumptions** сохраняет актуальные параметры стоимости.

Расчёт без браузера:

```text
python advisor.py --organism bacteria --application variant --budget 1200 --samples 6
python advisor.py --input saved-scenario.json --output saved-design.json
python -m unittest discover -s tests
```

Для проверки крайних значений, невозможного бюджета, округления целых запусков, единиц PE150 и математической вероятности служат тесты советника. Одинаковые вход и конфигурация дают одинаковый результат.

Авторы должны объяснять расчёты самостоятельно. Пользовательский интерфейс помогает представить результаты, но не заменяет реальные эксперименты, вклад двух участников и подготовку к вопросам преподавателя.
